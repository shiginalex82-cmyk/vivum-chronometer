# VIVUM — Хронометраж

Бесплатное PWA-приложение для хронометража электромонтажных работ на объекте.

## Возможности
- рабочие пакеты;
- этапы работ;
- производительное время и потери;
- причины простоев;
- история замеров;
- экспорт CSV;
- локальное хранение данных;
- офлайн-режим после первой загрузки;
- установка на главный экран iPhone.

## Установка на iPhone
1. Открыть опубликованную страницу в Safari.
2. Нажать «Поделиться».
3. Выбрать «На экран Домой».
4. Запустить значок VIVUM Хроно.

Версия: 0.1
