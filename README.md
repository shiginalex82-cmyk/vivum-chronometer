# VIVUM — Хронометраж

PWA-приложение для подготовки рабочего пакета и хронометража электромонтажных работ на объекте.

## Текущая версия 0.2.2
- три допуска: снабжение, инженер, монтажник;
- чек-листы под конкретный тип работ;
- точная закупленная номенклатура счёта №2689 для пилота;
- отдельный учёт подготовительных трудозатрат по ролям;
- технологическое производительное время;
- простои и причины потерь;
- отдельные операции внутри рабочего пакета;
- история и CSV-экспорт;
- локальное сохранение черновика и активного пакета;
- офлайн-PWA для iPhone.

## Методический принцип
Подготовка, технологическая работа, простои и технологические выдержки не смешиваются. Норма на единицу формируется только из валидированного технологического времени.

- `docs/METHODOLOGY.md` — разделение категорий времени и правила допуска.
- `docs/COST_MODEL.md` — связь трудоёмкости, себестоимости и коммерческой цены.

- `docs/ELECTRICAL_WORK_PACKAGES.md` — границы девяти пилотных рабочих пакетов электрики.
