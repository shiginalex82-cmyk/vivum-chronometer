# VIVUM — Методика хронометража и подготовительных трудозатрат

## 1. Разделение времени
- Подготовка снабжения — отдельно от технологической нормы.
- Инженерная подготовка — отдельно от технологической нормы.
- Внутренняя логистика и организация рабочего места монтажника — отдельно.
- Производительное технологическое время — база для нормы на единицу.
- Простои/потери — фиксируются отдельно и не увеличивают норму.
- Технологическая выдержка материалов — влияет на календарный срок, но не является трудозатратой.

## 2. Допуск рабочего пакета
Рабочий пакет запускается только после трёх подтверждений:
1. Снабжение готово.
2. Инженерная подготовка готова.
3. Монтажник фактически принял пакет в работу.

## 3. Формула данных пакета
Полная трудоёмкость пакета = подготовка снабжения + инженерная подготовка + внутренняя логистика монтажника + производительное технологическое время.

Организационные потери показываются отдельно и используются для анализа процесса, а не для формирования технологической нормы.

## 4. Для сметы
Технологическая норма считается по рабочей операции и объёму. Подготовка и организационное сопровождение должны попадать в смету отдельными строками/слоями стоимости, а не скрываться внутри цены одной точки или одного метра кабеля.
## 5. Два уровня детализации
- Массовый хронометраж: монтажник переключает только укрупнённые `observation_groups`.
- Исследовательский хронометраж: инженер при необходимости раскладывает группу на детальные `operations`.

Укрупнение не меняет технологический состав: каждая детальная операция должна входить ровно в одну группу своего пакета.

## 6. Численность бригады
Таймер хранит календарное время. Для нормы дополнительно рассчитывается человеко-время: `productive_person_time = productive_elapsed_time × crew_size`.
