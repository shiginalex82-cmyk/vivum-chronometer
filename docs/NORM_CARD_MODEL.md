# VIVUM — модель нормативной карточки

## 1. Назначение
Нормативная карточка связывает технологическую операцию, условия выполнения и подтверждённую трудоёмкость. Она создаётся только после фактических наблюдений.

## 2. Статусы
- `TEST` — данные собираются; использовать для цены нельзя.
- `PRELIMINARY` — есть первые повторяемые наблюдения; только внутренний ориентир.
- `WORKING` — норма применяется в рабочих расчётах с указанными ограничениями.
- `APPROVED` — норма утверждена владельцем методики.
- `RETIRED` — заменена новой редакцией, сохраняется для истории.

## 3. Вариант нормы
Одна операция может иметь несколько вариантов по условиям: материал основания, тип кабеля, высота, доступ, технология крепления, число линий в пучке и другие реально влияющие параметры.

Не использовать коэффициент, если технологический маршрут фактически другой. Для другого маршрута создаётся отдельный вариант/операция.

## 4. Человеко-время
Основная величина — `person_min`. Календарное время сохраняется отдельно.

Пример: 2 монтажника × 20 минут = 40 чел·мин.

## 5. Источник
Каждая карточка хранит `sourceMeasurementIds`. Исходные замеры не редактируются задним числом после публикации нормы.

## 6. Формирование кандидата
1. Отобрать только валидные наблюдения одной технологии и сопоставимых условий.
2. Исключить `T_loss` и `T_wait`.
3. Перевести производительное время в человеко-минуты.
4. Нормировать каждое наблюдение на его драйвер объёма.
5. Проверить выбросы и причины отклонений, не удаляя записи без объяснения.
6. Рассчитать медиану и среднее как диагностические показатели.
7. Инженер выбирает рабочую норму и фиксирует основание решения.

## 7. Минимум данных
До накопления устойчивой выборки приложение не должно автоматически объявлять значение нормативом. Количество наблюдений, число исполнителей, объектов и диапазон условий всегда показываются рядом с нормой.

## 8. Версионирование
Изменение технологии, инструмента, материала или границ операции создаёт новую версию нормативной карточки. Старая версия не перезаписывается.

JSON-контракт: `schemas/norm_card.schema.json`.
