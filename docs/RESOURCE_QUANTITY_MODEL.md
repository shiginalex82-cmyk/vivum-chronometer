# VIVUM — модель определения количества ресурсов v0.1

## Назначение
Модель переводит требования рабочего пакета в фактические количества материалов для производственной себестоимости.

Цепочка:
`Work Package → Resource Requirement → Quantity Driver / Consumption Rule → Resource Quantity Build → Production Cost Request`.

## Главное разделение
Наличие ресурса для допуска к работе не равно его расходу.

Примеры:
- монтажный пистолет должен быть доступен, но не списывается как расходник на каждую линию;
- газовый баллон должен быть доступен, но в себестоимость попадает доля баллона по подтверждённому ресурсу выстрелов;
- кабель считается по конкретной выбранной линии с утверждённым запасом;
- ТТК считается по длине на соединение, а не просто по числу коробок.

## Источники количества
1. `AUTO_DRIVER` — однозначный драйвер × коэффициент, например 10 коробок × 1.
2. `APPROVED_POLICY` — утверждённое правило расхода.
3. `MEASURED / PROJECT / MANUAL / SUPPLIER_DATA` — явно переданное количество с источником.

Автоматическое применение правила допускается только при статусе `WORKING` или `APPROVED`.
## Неопределённые правила пилота
Пока не утверждены числовые значения для:
- массы монтажного состава на подрозетник;
- технологического запаса кабеля;
- ресурса газового баллона в выстрелах;
- расхода маркировочного материала;
- длины ТТК на соединение;
- смешанного кабельного пучка, где длина нужна по каждому выбранному типу.

Такие позиции получают `NOT_DERIVED`; весь Resource Quantity Build имеет `complete=false`.

## Защита сметы
`build_production_request.py` отказывается создавать готовый Production Cost Request, если хотя бы один исходный Resource Quantity Build неполон.

Это исключает ситуацию, когда известные материалы случайно выдаются за полную материальную себестоимость.

## Контракты
- `data/package_resource_requirements.v2.json` — что требуется;
- `data/consumption_policy.template.json` — как определяется расход;
- `schemas/resource_quantity_request.schema.json` — вход;
- `schemas/resource_quantity_result.schema.json` — результат;
- `scripts/derive_resource_quantities.py` — строгий расчёт количества;
- `scripts/build_production_request.py` — агрегация полных результатов в запрос производственной себестоимости.

## Утверждённое правило газа
Для газового монтажного пистолета: **1 баллон = 1000 выстрелов / точек крепления**.
Расход для себестоимости: `Q_баллон = fastener_qty / 1000`. Дробное значение допустимо как распределённый расход. Закупочное округление выполняется отдельно.
