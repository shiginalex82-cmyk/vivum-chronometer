# VIVUM — модель драйверов объёма

## Зачем
Операции одного рабочего пакета могут масштабироваться по разным величинам. Поэтому стоимость пакета нельзя получать простым умножением «цены за метр» или «цены за точку».

## Основные драйверы
- `package` — один раз на рабочий пакет.
- `primary_qty` — основной объём пакета по его `primary_unit`.
- `secondary_qty` — дополнительный объём по `secondary_unit`.
- `block_qty` — число блоков подрозетников.
- `package_batch` — число замесов/партий.
- `route_length` — длина трассы/сегмента.
- `line_qty` — число самостоятельных линий.
- `line_end_qty` — число обрабатываемых концов линий.
- `fastener_qty` — число фактических точек крепления.

## Правило
Прямо измеряемые драйверы берутся из BIM/ведомости/факта. Производные вычисляются только по утверждённому технологическому правилу.

Например, `fastener_qty` нельзя молча принять равным длине в метрах: сначала должен быть определён шаг крепления и правила для поворотов/концов/ветвлений.

Машиночитаемый справочник: `data/driver_rules.v1.json`.
