# VIVUM — расчётчик трудоёмкости и стоимости v0.1

## 1. Принцип
Расчёт идёт снизу вверх: рабочий пакет → операции → драйверы объёма → норматив человеко-минут → роль → часовая стоимость.

Никакая цена не создаётся без нормативной карточки и ставки роли.

## 2. Вход
Для каждого рабочего пакета передаются:
- стабильный `workPackageCode`;
- фактические драйверы объёма (`primary_qty`, `block_qty`, `route_length`, `fastener_qty`, `secondary_qty` и др.);
- подготовительные человеко-минуты снабжения, инженера и монтажника;
- при необходимости условия варианта технологии.

## 3. Операция
`OperationPersonMin = NormPersonMinPerDriver × DriverQuantity`.

`OperationLaborCost = OperationPersonMin / 60 × RoleHourlyCost`.

Для `FIXED_PACKAGE` количество автоматически равно 1. Для `BATCH` число партий/замесов задаётся фактически.

## 4. Подготовка
Подготовка рассчитывается отдельно по ролям и не маскируется внутри нормы одной штуки/метра.

## 5. Строгий режим
В расчёт попадают только нормы со статусом `WORKING` или `APPROVED` и ненулевой утверждённой величиной.

Если отсутствует:
- драйвер объёма;
- рабочая/утверждённая норма;
- ставка роли;

строка получает `NOT_CALCULATED`, а весь расчёт — `complete=false`. Частичная сумма показывается отдельно и не выдаётся за полную стоимость.

## 6. Что пока не входит
Материалы, оборудование, аренда механизации, накладные расходы, риск, прибыль и налоги пока не рассчитываются этим скриптом. Это следующий слой поверх трудовой себестоимости.

## 7. Файлы
- `scripts/estimate_labor.py` — расчётчик.
- `data/norm_cards.template.json` — пустая база норм без выдуманных значений.
- `data/rate_card.template.json` — пустые ставки ролей.
- `schemas/estimate_request.schema.json` — контракт входного задания.
