# VIVUM — модель трудоёмкости и стоимости

## 1. Базовые величины
- `elapsed_min` — календарное время выполнения.
- `crew_size` — число одновременно работающих исполнителей.
- `person_min = elapsed_min × crew_size` — трудоёмкость.
- Нормы и себестоимость считаются в человеко-минутах/часах, а не только по таймеру.

## 2. Категории времени
- `T_supply_prep` — снабжение/комплектация.
- `T_engineer_prep` — инженерная подготовка.
- `T_installer_prep` — внутренняя логистика и организация рабочего места.
- `T_tech` — производительное технологическое время.
- `T_loss` — простои/организационные потери.
- `T_wait` — технологическая выдержка; календарное время, не человеко-часы.

## 3. Нормирование
Норма операции = валидированная трудоёмкость `T_tech_person_min` / соответствующий драйвер объёма.

Драйвер задаётся для каждой операции отдельно: пакет, партия, штука, блок, метр, линия, конец линии, крепление, кабель, коробка, соединение или опуск.

Подготовка партии не умножается на каждую единицу. Она рассчитывается один раз на пакет/партию согласно `measurement_scope`.

## 4. Себестоимость
`LaborCost = Σ(T_role_h × Rate_role)`.

Снабжение, инженер, монтажник и другие роли могут иметь разные часовые ставки. `T_loss` хранится отдельно и включается в стоимость только по классификации причины.

## 5. Цена клиенту
Производственная себестоимость + накладные расходы + управление + риск + прибыль + налоги/договорные условия.

Цена «за точку» может быть итоговым коммерческим представлением, но не источником нормы.
