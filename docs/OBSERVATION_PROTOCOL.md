# VIVUM — протокол хронометражного наблюдения

## 1. Единица наблюдения
Замер выполняется на полноценном рабочем пакете, а не на случайной отдельной операции без контекста.

## 2. Обязательные условия записи
Для каждого наблюдения фиксируются:
- объект и зона;
- вид рабочего пакета;
- исполнитель/бригада;
- объём и единица измерения;
- материал основания/тип кабеля/технологический маршрут;
- число работников;
- подготовительные минуты по ролям;
- производительное время;
- простои и причины;
- времена операций;
- комментарии об отклонениях.

## 3. Человеко-минуты
Если операцию 20 минут выполняют два человека, трудоёмкость = 40 человеко-минут. Продолжительность и трудоёмкость должны различаться.

## 4. Валидность
Наблюдение не используется как нормативное, если:
- рабочий пакет стартовал без готовности материалов/инструмента/зоны;
- технология изменилась в середине замера без фиксации;
- объём неизвестен или посчитан после факта ненадёжно;
- значимая часть простоя попала в производительное время;
- результат потребовал переделки из-за собственного дефекта.

## 5. Серийность
Для подрозетников сравниваются пакеты сопоставимого основания и конфигурации. Для кабеля отдельно измеряются одиночные линии и группы линий/пучки.

## 6. Норматив после пилота
Один замер не становится нормой. Сначала собирается серия сопоставимых наблюдений, затем анализируется разброс, причины отклонений и устойчивое центральное значение. Только после этого версия нормы публикуется в нормативной базе.
